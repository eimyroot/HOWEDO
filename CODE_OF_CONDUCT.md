# Code of Conduct

## Our standard

We want collaboration in this repository to be professional, constructive, and safe for everyone involved.

Contributors, maintainers, reviewers, and users are expected to:

- communicate respectfully and focus criticism on ideas, code, evidence, and outcomes;
- avoid harassment, discrimination, threats, intimidation, and personal attacks;
- respect privacy, security boundaries, and confidential information;
- accept reasonable moderation and review decisions without retaliation;
- report security-sensitive matters through the repository security process rather than public issues.

Unacceptable behavior includes harassment, discriminatory or demeaning language, deliberate disruption, doxxing, sexualized conduct, threats, and publishing private information without permission.

## Scope

This Code of Conduct applies in repository issues, pull requests, discussions, reviews, project spaces, and other project-related communication channels.

## Enforcement

Repository maintainers may edit or remove content, close or lock conversations, reject contributions, or restrict participation when behavior violates this Code of Conduct.

Serious or repeated violations may result in temporary or permanent exclusion from project spaces.

## Reporting

For conduct concerns, contact the repository owner privately. Do not include sensitive personal information in public issues.

Reports should include enough context to evaluate what happened while minimizing unnecessary disclosure of personal data.

## Good-faith principle

Disagreement is expected. Abuse is not. Technical rigor, direct criticism, and strong opinions are welcome when expressed in a way that still permits productive collaboration.
