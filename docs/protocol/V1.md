# HOWEDO Protocol v1

Canonical protocol identifier: `howedo.protocol.v1`.

## Compatibility rule

Within v1, schemas may only gain optional fields or tighter documentation that does not invalidate previously valid v1 payloads. Any breaking wire/storage change requires a new protocol major (`howedo.protocol.v2`).

## Stable v1 schemas

- `resource-revision.schema.json`
- `continuity-snapshot.schema.json`
- `witness-record.schema.json`
- `continuity-event.schema.json`
- `recovery-checkpoint.schema.json`

## Persistence contract

`StorageAdapter` implementations persist HOWEDO state but do not define continuity semantics. The contract permits immutable revision registration, one-time head initialization, expected-head activation, witness persistence, and append-only events.

After initialization, authoritative heads may only move through `activate_if_head(expected, replacement)`.

## PostgreSQL reference adapter

The packaged migration `0001_protocol_v1` establishes the v1 PostgreSQL schema. Migrations are monotonic and recorded in `howedo_schema_migrations`. An adapter must reject migrations or protocol versions it does not understand instead of guessing compatibility.

PostgreSQL is an optional reference adapter, not a required HOWEDO runtime dependency.
